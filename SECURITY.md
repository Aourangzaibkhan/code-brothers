# Security Policy

Code Brothers is secure-by-default: no default passwords, Argon2id hashing, TOTP 2FA,
AES-256-GCM envelope-encrypted credential vault, SSRF firewall, sandboxed expressions,
HMAC-verified webhooks and full secret redaction in logs.

## Reporting a Vulnerability
Please report vulnerabilities privately to the repository maintainers via GitHub
Security Advisories ("Report a vulnerability"). Do not open a public issue for
security problems. We aim to acknowledge reports within 72 hours.
